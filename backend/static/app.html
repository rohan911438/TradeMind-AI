Honest scope. The live feed is simulated because no free real-time NSE tick feed exists. A real feed plugs into the same event-bus interface.

The model is trained on real NSE 5-minute bars with a time-ordered, purged train/validation/test split, so it never sees the future. Short-term prediction is noisy, which is exactly why RiskGuard sits between every signal and every order.

This is an educational prototype inspired by HFT architecture, not an exchange-grade system and not financial advice.
